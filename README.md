# YoloDetector - YOLO Object Detection & Real-Time Edge Analytics

---

### 🌐 English

High-throughput object detection and spatial tracking system utilizing YOLO architecture. Designed for real-time video processing at the edge.

#### Key Features:
* Real-time multi-class object detection
* Optimized frame buffer pipeline
* Configurable confidence and NMS thresholds

* **Tech Stack**: `Python` `YOLO` `OpenCV` `PyTorch`

---
